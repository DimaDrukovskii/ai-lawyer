# База знаний

Сюда `python -m lawyer research` складывает результат: `knowledge/<run_id>/`.

```
knowledge/
├── LATEST                  # id последнего прогона (его читает review)
└── <run_id>/
    ├── README.md           # индекс: сколько утверждений доверено/отклонено/не подтверждено
    ├── claims.json         # все утверждения со статусом, вердиктом, источниками
    ├── gaps.json           # открытые пробелы и упавшие зоны
    └── zones/<zone>.md     # человекочитаемая выжимка по зоне
```

В «доверенное» попадает только то, что подтвердил независимый верификатор **и** что опирается на
первоисточник (ФНС, Минфин, pravo.gov.ru, суды, КонсультантПлюс/Гарант, оферты площадок).
Мнение агента и утверждения, подтверждённые одним блогом, в доверенное не попадают. Это правило
зашито в код (`src/lawyer/research/knowledge.py`), а не в промпт.

Прогоны версионируются в git: так видно, что изменилось в праве между прогонами.
